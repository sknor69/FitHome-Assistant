# 🏡 FitHome Assistant — Assistente Virtual de Treinos em Casa

Bem-vindo ao repositório do meu projeto desenvolvido para o Lab **"Construa Seu Assistente Virtual Com Inteligência Artificial"** da DIO.

## 🎯 O Problema
Muitas pessoas desejam iniciar uma rotina de exercícios físicos, mas enfrentam barreiras como a falta de tempo, o custo de academias ou a ausência de equipamentos em casa.

## 💡 A Solução
O **FitHome Assistant** é um agente inteligente focado em **calistenia e peso corporal**. Ele ajuda usuários a planejarem treinos rápidos, seguros e eficientes utilizando apenas o próprio corpo, sem precisar de nenhum equipamento externo.

---

## 🛠️ Estrutura do Projeto (Os 6 Passos do Desafio)

1. **Documentação (`docs/documentacao.md`):** Definição do escopo, persona e regras do assistente.
2. **Base de Conhecimento (`data/exercicios.json`):** Dados estruturados contendo exercícios de peso corporal validados.
3. **Prompts (`docs/prompt.md`):** Instruções de comportamento para garantir que a IA não invente dados ou sugira equipamentos.
4. **Aplicação Funcional (`src/app.py`):** Script em Python que integra a lógica e a base de dados.
5. **Avaliação (`docs/avaliacao.md`):** Testes práticos para verificar restrições e acurácia.
6. **Pitch (`README.md`):** Esta apresentação do projeto.
